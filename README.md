# Apple sustainability infographic

Static HTML infographic with Tailwind CSS and Chart.js loaded from CDNs. Open `index.html` in a browser with internet access; there is no build or test runner.
The optional Gemini ideas generator has an empty API key and is not configured. Do not embed a private API key in this public client; a working integration needs a server-side credential boundary.
Review the dated environmental/financial figures against their sources before using the infographic for decisions.
